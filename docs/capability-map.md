# Capability Map

AegisSec AI v1.0.0 provides 115 curated native skills plus optional guarded access to the reviewed upstream 818-skill library.

| Capability | Primary role | Native domains |
|---|---|---|
| Security strategy / risk | Security Lead / GRC | core, governance, reporting |
| Authorised offensive validation | Red-Team Lead | red-team |
| SOC / detections / hunting | SOC / Detection Engineer | blue-team, security-platform |
| Incident response / forensics | Incident Commander / DFIR | dfir |
| Application security | AppSec Engineer | appsec |
| CI/CD / supply chain | DevSecOps Security | devsecops |
| Identity / PAM / workload identity | Identity Security Engineer | identity-security |
| Data / secrets / keys / recovery | Data Security Engineer | data-security |
| Security platforms / telemetry / SOAR | Security Platform Engineer | security-platform |
| Customer deployment / integration | Forward Deployed Security Engineer | forward-deployed-engineering |
| Cloud | Cloud Security | cloud |
| Threat intelligence | Threat Intelligence | threat-intel |
| AI / agentic / MCP | AI Security | ai-security |
| Purple team | Purple Team | purple-team |
| Mobile / OT / WordPress | Specialist routing | platform |

Use the router to select the smallest sufficient set. Cross-domain tasks may load a secondary role, but one role should remain accountable for the final decision.
