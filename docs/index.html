Governed execution

From intelligence to action.

AegisSec uses an explicit state machine so the agent cannot silently escalate the target, privilege, scope or impact.

  1. 01

    Discover

    Understand context, assets, objectives and authority.

  2. 02

    Plan

    Select skills, tools, evidence requirements and safeguards.

  3. 03

    Approve

    Apply policy and require human approval where risk demands it.

  4. 04

    Execute

    Perform only scoped, permitted and traceable actions.

  5. 05

    Verify

    Correlate evidence, validate impact and check assumptions.

  6. 06

    Close

    Report findings, remediation, residual risk and next actions.

Architecture

Security policy stays above skills and tools.

The trust hierarchy is deliberate: legal authority and AegisSec policy outrank human operational state, curated skills, third-party content and arbitrary input.

Core operating rules

No target + no scope + no authorisation = no active testing.

Third-party skills are knowledge, not permission.

Production changes require approval, verification and rollback planning.

High-risk offensive actions remain human-gated and scope-bound.

Quick start

Point your AI agent at AegisSec.

Start with AGENTS.md. The router selects the appropriate role, curated skills and playbook while the policy layer controls execution.

terminal
git clone https://github.com/<owner>/AegisSec-AI.git
cd AegisSec-AI
python -m pip install -r requirements.txt
python scripts/aegissec.py validate

# Optional upstream skill library
npm run skills:install-upstream
npm run skills:lock
python scripts/aegissec.py upstream-status
Vulnerability Intelligence

From package inventory to context-aware priority

OSV discovery with GitHub Advisory, NVD, CISA KEV and FIRST EPSS enrichment. AegisSec correlates identifiers, adds reachability/exposure/business context, then produces explainable P0–P4 priorities and a per-package fix plan with deadlines — published as a report, SARIF alerts, a self-updating GitHub issue or a pull-request gate — without granting automatic production-change authority.
