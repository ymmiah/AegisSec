Real-world problem-solving registry for security work

Tell it the security problem. Get a governed workflow, evidence and a fix plan.

AegisSec AI is a cybersecurity workspace for AI agents. It turns messy security work into repeatable workflows that start with authorisation. You state a real problem, such as a CVE backlog, a risky PR, a phishing report or a cloud IAM review. AegisSec routes it to the right playbook under hard rules, and you get evidence plus a fix plan, with a human approval gate before anything consequential.

How it works

One journey for every job.

Every problem card follows the same six steps. The AI agent does the legwork, and you stay the accountable human at the points that matter.

  1. 01

    Discover

    You: describe the problem and what's in scope.
    Agent: inventories assets, runs read-only scans, gathers evidence.

  2. 02

    Plan

    Agent: picks the playbook and skills, then proposes exact steps, the evidence needed and a rollback.

  3. 03

    Approve

    You: approve, change or refuse. Active testing needs a passing check-scope. Production changes need explicit sign-off.

  4. 04

    Execute

    Agent: does only the approved, scoped, logged actions. Destructive actions are denied outright.

  5. 05

    Verify

    Agent: re-scans or retests and checks the evidence against its assumptions.
    You: confirm the result.

  6. 06

    Close

    Out: findings, the fix plan, residual risk and the next action, written from templates/.

What you get

Four pieces, one set of rules.

Use one or all four. The same policy layer (AGENTS.md, policy/, tools/action-risk.yaml) governs every one.

VI

Vulnerability intelligence

scripts/vuln_intel.py combines OSV with GitHub Advisory, NVD, CISA KEV and EPSS. Your asset context turns that into a P0–P4 fix plan, delivered as Markdown, JSON or SARIF.

PB

Playbooks + skills

20 playbooks and 10 operational Agent Skills for Claude Code, Codex, Cursor, Gemini CLI and Copilot. Specialist skill packs are there when you need more depth.

RH

Runtime harness

A BYOK chatbot over Anthropic, OpenAI or NVIDIA NIM (aegissec_agent/). Every tool call clears the policy gate in code. The tools are read-only by design.

CI

CI workflow

Add one workflow file to get a weekly scan, alerts in the GitHub Security tab, a fix-plan issue that keeps itself up to date and a PR gate on new findings.

Supporting depth (not the headline)

Behind the registry sit 115 curated security knowledge files across red, blue, purple, DFIR, AppSec, DevSecOps, cloud, identity and AI security. There are also 64 senior specialist skills and an optional, pinned and audited library of 818 upstream skills. Upstream skills are knowledge, not permission: they can never override AegisSec scope or approval rules. Baselines: MITRE ATT&CK v19.2, D3FEND v1.6.0, NIST CSF 2.0, NIST SP 800-61r3, OWASP, CIS Controls.

Quick start

Running in two minutes.

Clone, validate, then run problem #01 on the bundled example. To use it from your own coding agent, install the skills and ask it in plain English.

BYOK chatbot: export NVIDIA_API_KEY=… then python scripts/aegissec_agent.py --provider nvidia. Keys stay in your environment and are never committed.

terminal
git clone https://github.com/ymmiah/AegisSec.git
cd AegisSec
python -m pip install -r requirements.txt
python scripts/aegissec.py validate

# Problem #01: dependency CVEs → fix plan
python scripts/vuln_intel.py scan \
  examples/vulnerability-intelligence/components.json \
  --context examples/vulnerability-intelligence/context.yaml \
  --format markdown

# Use it from your coding agent
npx skills add ymmiah/AegisSec -s aegissec -s aegissec-vuln-scan
