# AegisSec AI brand assets

The `docs/assets/brand/` directory contains the approved AegisSec AI v1 identity supplied for this release.

## Assets

- `aegissec-icon.jpg` / `.webp` — shield icon for avatars, favicons and compact UI.
- `aegissec-lockup.jpg` / `.webp` — shield plus AegisSec AI wordmark.
- `aegissec-hero.jpg` / `.webp` — wide README/social/landing-page banner.
- `icon-64.png`, `icon-180.png`, `icon-192.png`, `icon-512.png` — resized icon derivatives for web/app use.
- `docs/favicon.ico` — browser favicon generated from the approved icon.

## Usage principles

1. Preserve the shield geometry, A motif and cyan/blue/violet colour language.
2. Do not stretch, skew, recolour or place low-contrast text over the mark.
3. Keep adequate clear space around the icon and wordmark.
4. Prefer the wide hero artwork for GitHub/social previews and the compact icon for favicons/avatars.
5. Do not imply endorsement by third-party vendors or security organisations without permission.
