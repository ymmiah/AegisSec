# CI/CD Security Review

1. Map repositories, runners, identities, secrets, artefact stores and environments.
2. Review branch protection, approvals and deployment gates.
3. Minimise token and workflow permissions.
4. Pin/trust third-party actions and dependencies.
5. Add SAST, SCA, secret scanning and IaC/container checks with triage ownership.
6. Generate SBOM/provenance for releases where appropriate.
7. Protect production environments with separate credentials and human approval.
8. Test rollback and compromised-pipeline response.
