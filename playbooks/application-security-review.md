# Application Security Review

1. Identify architecture, data flows, trust boundaries and roles.
2. Threat-model critical business actions.
3. Review authentication, authorisation, session and secrets handling.
4. Review untrusted-input handling, output encoding and unsafe interpreters.
5. Review dependency/supply-chain and deployment configuration.
6. Validate logging, monitoring, error handling and fail-safe behaviour.
7. Map verified gaps to OWASP Top 10:2025 / ASVS 5.0.0 where appropriate.
8. Prioritise fixes by exploitability and business impact.
