# Phishing Response

1. Preserve the original message safely.
2. Analyse headers, sender authentication, URLs and attachments in controlled tooling.
3. Extract indicators and search mail/security telemetry.
4. Identify users who received, clicked, authenticated or executed content.
5. Revoke sessions/reset credentials only where evidence justifies it.
6. Block malicious infrastructure/content where safe.
7. Notify affected users and monitor for follow-on activity.
