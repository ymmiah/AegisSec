# SOC Alert Triage

1. Validate alert source, time range and affected identity/asset.
2. Check data quality and false-positive conditions.
3. Enrich with identity, endpoint, network and cloud context.
4. Build a short event timeline.
5. Determine likely benign/suspicious/malicious state and confidence.
6. Recommend contain, escalate, monitor or close.
7. Preserve key evidence and document rationale.
8. Feed validated behaviour back into detection engineering.
