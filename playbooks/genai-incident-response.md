# GenAI / Agentic Incident Response

1. Declare incident ownership and preserve agent/model/tool telemetry.
2. Identify affected agents, users, tools, MCP servers, memory/RAG stores, credentials and external actions.
3. Contain by revoking delegated credentials and disabling only risky capabilities.
4. Preserve prompts/configuration/policy versions and relevant retrieved content.
5. Determine whether data disclosure, tool misuse, memory poisoning, model/dependency compromise or identity abuse occurred.
6. Restore trusted configuration/data and rotate affected secrets.
7. Retest prompt/tool/memory boundaries and runtime policy.
8. Record lessons, control changes and monitoring improvements.
