# Cloud Security Review

1. Identify tenant/account/project structure and critical workloads.
2. Review federation, MFA, privileged roles and service identities.
3. Find public exposure and unintended trust relationships.
4. Review network segmentation, encryption and key ownership.
5. Validate audit logs, threat detection and retention.
6. Review backups, recovery and break-glass access.
7. Prioritise read-only fixes and guardrails before intrusive testing.
