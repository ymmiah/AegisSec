# Task Classification

## DEFENSIVE
Examples: secure code review, log analysis, IOC matching, detection rules, architecture review, hardening, patch advice, incident containment planning.

## ASSESSMENT
Examples: scanning an authorised website, testing an authorised API, validating TLS/configuration, rate-limited discovery on named hosts, safe access-control verification.

## LAB
Examples: CTF, local vulnerable VM, demo repository, intentionally vulnerable web app, synthetic phishing simulation, malware sandbox.

## PROHIBITED
Examples: destructive payloads, indiscriminate scanning, persistence on a third-party system, extortion, covert credential theft, uncontrolled data exfiltration, bypassing organisational safeguards to hide activity.
