# Contributing

Contributions are welcome when they improve defensive value, assessment quality, evidence handling or safety.

Requirements:
- keep active-testing guidance scoped and non-destructive by default;
- never add live secrets, customer data or unauthorised target information;
- cite authoritative sources for factual framework changes;
- separate scanner output from verified findings;
- include remediation and verification steps;
- run `python scripts/aegissec.py validate` before submitting a pull request.
