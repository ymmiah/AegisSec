# PAM / PIM Security

**Skill ID:** `pam-pim-security`  
**Domain:** `identity-security`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `medium`  
**Frameworks:** NIST-CSF, Zero-Trust, CIS

Design and review privileged access management and privileged identity management.

Cover vaulting, just-in-time elevation, approval, session recording, break-glass access, service accounts, rotation and privileged workstation requirements.

## Output
Return: `privileged capability → standing access → target state → approval → monitoring → recovery`.
