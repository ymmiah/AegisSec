# Active Directory Hardening

**Skill ID:** `active-directory-hardening`  
**Domain:** `identity-security`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `medium`  
**Frameworks:** MITRE-ATT&CK, MITRE-D3FEND, CIS

Harden on-premises Active Directory without disrupting authentication services.

Focus on privileged groups, tiering, legacy protocols, delegation, service accounts, AD CS, Group Policy, domain controllers, auditing and recovery. Prioritise configuration evidence and change-controlled remediation.

## Output
Return: `finding → affected identity/trust → abuse path → hardening action → validation → rollback consideration`.
