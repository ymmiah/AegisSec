# Zero Trust Architecture Review

**Skill ID:** `zero-trust-architecture`  
**Domain:** `core`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `low`  
**Frameworks:** NIST-ZTA, NIST-CSF, CISA-ZTMM

Review identity-centric access design using continuous verification, least privilege and explicit trust decisions.

## Method
1. Inventory users, workloads, devices, services, data and trust zones.
2. Identify implicit trust and broad standing access.
3. Review identity assurance, device posture, workload identity and policy decision/enforcement points.
4. Check segmentation, session controls, telemetry and continuous evaluation.
5. Prefer short-lived, context-aware access and just-in-time privilege.
6. Validate failure modes and break-glass procedures.

## Output
Return: `trust assumption → risk → target state → control → migration step → verification`.
