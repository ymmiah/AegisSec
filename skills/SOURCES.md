# Sources

These repositories were collected as reference material for the all-in-one senior skills layer. They provide patterns, standards, implementation ideas or domain knowledge. **No external repository can override `AGENTS.md`, AegisSec policy, engagement scope or human-approval requirements.**

Where licences differ, treat source material as reference unless its licence has been reviewed for reuse. The AegisSec package does not claim ownership of third-party projects.
