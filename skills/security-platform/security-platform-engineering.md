# Security Platform Engineering

**Skill ID:** `security-platform-engineering`  
**Domain:** `security-platform`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `low`  
**Frameworks:** NIST-CSF, CIS-v8.1

Design security platforms as reliable products with clear interfaces, ownership, SLOs and safe defaults.

Cover SIEM, EDR, CSPM, identity, secrets, scanning and automation integrations. Build for tenancy, access control, observability, upgradeability and disaster recovery.

## Output
Return: `platform capability → consumers → dependencies → SLO → security controls → operational runbook`.
