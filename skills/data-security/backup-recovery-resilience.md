# Backup, Recovery & Cyber Resilience

**Skill ID:** `backup-recovery-resilience`  
**Domain:** `data-security`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `low`  
**Frameworks:** NIST-CSF, NIST-800-61r3

Validate that backups support real recovery from ransomware, destructive error and platform compromise.

Cover immutability, isolation, identity separation, restore testing, recovery objectives, key recovery, dependency order and clean-room recovery.

## Output
Return: `service → backup coverage → isolation → RPO/RTO → restore evidence → gaps → recovery action`.
