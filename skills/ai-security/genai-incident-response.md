# GenAI / Agentic Incident Response

**Skill ID:** `genai-incident-response`  
**Domain:** `ai-security`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `high`  
**Frameworks:** NIST-800-61r3, OWASP-Agentic-Applications-2026, OWASP-LLM-Top10-2026

Respond to suspected prompt injection, data disclosure, compromised tools, poisoned memory/RAG, rogue agent behaviour or model-supply-chain compromise.

Preserve agent/tool telemetry, isolate risky capabilities, revoke delegated credentials, snapshot relevant configuration, assess data exposure, restore trusted state and retest controls.

## Output
Return: `incident hypothesis → containment → evidence → affected trust boundaries → eradication → recovery → lessons`.
