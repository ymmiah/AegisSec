# Agent Memory Security

**Skill ID:** `agent-memory-security`  
**Domain:** `ai-security`  
**Default mode:** `DEFENSIVE`  
**Operational risk:** `high`  
**Frameworks:** OWASP-Agentic-Applications-2026, OWASP-Agentic-Skills-Top10-1.0-2026

Protect short-term and long-term agent memory from poisoning, cross-user leakage, stale instructions and unsafe persistence.

Validate provenance, tenant isolation, expiry, write permissions, redaction, conflict resolution and safe deletion.

## Output
Return: `memory store → writer/readers → trust → retention → poisoning controls → test`.
